# Arch Studio Website

This project is a sophisticated portfolio website for an architecture studio, built to beautifully showcase their innovative projects, introduce their team, and provide a clear way for clients to connect. It's built for a fast, accessible user experience and provides an intuitive content management system, making updates a breeze.

## Description

The Arch Studio website is a production-grade, multi-page application designed for architectural firms to present their portfolio in a modern and accessible way. It emphasizes elegant design, dynamic content delivery, and a seamless user experience, making it an excellent platform for studios to attract new clients and talent.

## Usage

Navigating the Arch Studio website is straightforward, allowing visitors to explore the studio's work and ethos.

### Pages

- **Home (`/`)**: Discover the studio's vision through an engaging hero slider, learn about their approach in the "Welcome" section, meet the small but impactful team, and explore a selection of featured projects.
- **Portfolio (`/portfolio`)**: Browse a comprehensive grid of all architectural projects. Clicking on any project card will take you to a dedicated detail page.
- **Individual Project (`/portfolio/[slug]`)**: View in-depth details about a specific project, including a large hero image, a description, and the completion date. A "Back to Portfolio" button makes navigation easy.
- **About Us (`/about`)**: Delve into the studio's history and values in the "Our Heritage" section. Get to know the leadership team, complete with their roles, avatars, and social media links.
- **Contact (`/contact`)**: Find all the ways to get in touch. This page features contact details for the studio's offices, an interactive map showcasing locations, and a submission form for inquiries.

### Interacting with the Map

On the Contact page, you can interact with the map to view office locations. You can click on the "View on Map" buttons next to each office's details to highlight that location on the map and open its popup with directions.

## Features

- **Dynamic Hero Slides**: Engaging, auto-rotating hero section on the homepage with project showcases.
- **Responsive Image Handling**: Images are optimized and served responsively for various screen sizes, ensuring fast loading and a great visual experience.
- **Interactive Map**: A Leaflet-powered map on the contact page allows users to view office locations and get directions.
- **Contact Form with Validation**: A user-friendly contact form featuring client-side input validation to ensure accurate submissions.
- **Rich Content Management**: Built with Sanity CMS, enabling easy updates to projects, team members, and page content without touching code.
- **Smooth Animations**: Subtle and meaningful animations powered by Framer Motion for an enhanced user interface.
- **SEO Optimized**: Each page is crafted with robust metadata, OpenGraph tags, and semantic HTML for strong search engine visibility.
- **Accessibility First**: Designed with accessibility in mind, using semantic HTML, ARIA attributes, and keyboard navigation support.
- **Modern Navigation**: Responsive header with clear navigation links and a mobile-friendly menu.
- **Error Handling**: Dedicated error and not-found pages for a graceful user experience.
